# 마이페이지 참고 자료

## 전체 목적

사용자의 기록과 누적 정보를 한곳에서 확인하는 화면이다.

## 화면 구성

- 사용자 이름
- 사용자 이메일
- 최근 기록 목록
- 누적 섭취 요약
- 사진 입력 비율 또는 텍스트 입력 비율
- 기록 수정 또는 삭제 진입 버튼

## 동작 규칙

- 사용자 계정별 기록만 보여준다.
- 기록은 최신 순으로 정리한다.
- 필요한 경우 상세 기록 화면으로 이동한다.
- 개인정보는 과도하게 노출하지 않는다.

## 참고 배치

```text
┌──────────────────────────────┐
│ ← 뒤로        마이페이지    │
│                              │
│  사용자 이름                 │
│  user@example.com            │
│                              │
│  오늘 / 주간 섭취 요약       │
│  [ 총 칼로리 / 기록 수 ]      │
│                              │
│  최근 기록 목록              │
│  - 김밥 / 420kcal            │
│  - 샐러드 / 180kcal          │
│  - 치킨 / 680kcal            │
│                              │
│  [ 내 기록 보기 ]            │
│  [ 설정 ]                    │
└──────────────────────────────┘
```
