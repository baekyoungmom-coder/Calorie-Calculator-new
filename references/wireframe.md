# 와이어프레임 구도

이 문서는 **Calorie Calculator** 앱의 화면 구조를 정리한 참고용 와이어프레임이다.
실제 디자인 완성본이 아니라, 화면 배치와 흐름을 설명하기 위한 문서다.

## 1. 시작 화면

```text
┌──────────────────────────────┐
│          Calorie             │
│         Calculator           │
│                              │
│  음식 사진 또는 텍스트로      │
│  칼로리를 간편하게 기록하기   │
│                              │
│  [ 사진으로 시작 ]           │
│  [ 직접 입력 시작 ]          │
│                              │
│  [ 로그인 / 계속하기 ]       │
└──────────────────────────────┘
```

## 2. 입력 방식 선택 화면

```text
┌──────────────────────────────┐
│ ← 뒤로        입력 선택      │
│                              │
│  어떤 방식으로 입력할까요?   │
│                              │
│  ┌────────────────────────┐  │
│  │ 사진으로 입력하기       │  │
│  │ 음식 사진 업로드        │  │
│  └────────────────────────┘  │
│                              │
│  ┌────────────────────────┐  │
│  │ 텍스트로 입력하기       │  │
│  │ 음식 이름 / 양 / 식사종류│ │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

## 3. 사진 입력 화면

```text
┌──────────────────────────────┐
│ ← 뒤로        사진 입력      │
│                              │
│  [ 사진 업로드 영역 ]         │
│  ┌────────────────────────┐  │
│  │   사진 미리보기         │  │
│  └────────────────────────┘  │
│  [ 카메라 촬영 ] [ 갤러리 ]   │
│                              │
│  음식 이름: [ 자동/선택 ]     │
│  양:       [ 입력 ]          │
│  식사 종류: [ 아침/점심/저녁 ]│
│  메모:     [ 선택 입력 ]     │
│                              │
│  [ 칼로리 계산 ]              │
└──────────────────────────────┘
```

## 4. 텍스트 입력 화면

```text
┌──────────────────────────────┐

│                              │
│  음식 이름: [             ]  │
│  양:       [             ]   │
│  식사 종류: [ 아침 ▼ ]       │
│  메모:     [             ]   │
```


## 9. 화면 흐름 요약

```text
시작 화면
   ↓
입력 방식 선택
   ↓
사진 입력 또는 텍스트 입력
   ↓
칼로리 결과
   ↓
저장
   ↓
오늘 기록 / 마이페이지
```

## 10. 작성 규칙

- 화면은 단순하고 읽기 쉽게 구성한다.
- 사진 입력과 텍스트 입력의 흐름을 분리한다.
- 결과 화면에서는 추정치임을 분명히 보여준다.
- 저장 후에는 오늘 기록이나 마이페이지에서 다시 확인할 수 있게 한다.
- 관리자 화면은 일반 사용자에게 노출하지 않는다.
