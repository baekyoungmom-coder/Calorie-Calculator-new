# 로그인 화면 참고 자료

## 전체 목적

사용자가 Google 계정으로 로그인해 식사 기록을 시작하는 화면이다.

## 화면 구성

- 서비스 이름
- 한 줄 소개
- Google 로그인 버튼
- 로그인 안내 문구
- 개인정보 최소 수집 안내

## 동작 규칙

- Google 로그인 성공 시 홈으로 이동한다.
- 로그인 실패 시 짧고 명확한 오류 메시지를 보여준다.
- 로그인 중에는 중복 클릭을 막는다.
- 로딩 중 상태를 표시한다.

## 참고 배치

```text
┌──────────────────────────────┐
│         Calorie Calculator   │
│                              │
│  음식 기록을 더 쉽게          │
│  남길 수 있는 앱             │
│                              │
│  [ Google로 로그인 ]         │
│                              │
│  개인정보는 최소한만 수집    │
└──────────────────────────────┘
```
