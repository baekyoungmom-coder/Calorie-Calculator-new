# 결과 화면 참고 자료

## 전체 목적

입력된 음식 정보와 사진을 바탕으로 추정 칼로리를 보여주는 화면이다.

## 화면 구성

- 음식명 또는 사진 요약
- 추정 칼로리
- 식사 종류
- 양 정보
- 기록 일시
- 수정 버튼
- 저장 버튼
- 다시 입력 버튼
- 신뢰도 또는 추정 안내 문구

## 동작 규칙

- 결과는 항상 추정치로 표시한다.
- 사용자가 수정할 수 있는 상태를 유지한다.
- 저장 성공과 실패를 분명히 구분한다.
- 저장 후 오늘 기록 화면으로 이어질 수 있게 한다.

## 참고 배치

```text
┌──────────────────────────────┐
│ ← 뒤로        결과 확인      │
│                              │
│  음식명 / 사진 요약           │
│  ┌────────────────────────┐  │
│  │   추정 칼로리          │  │
│  │   420 kcal             │  │
│  └────────────────────────┘  │
│                              │
│  음식명: 김밥                 │
│  양: 1줄                      │
│  식사 종류: 점심              │
│  신뢰도: 중간                 │
│                              │
│  [ 수정하기 ]                 │
│  [ 저장하기 ]                 │
│  [ 다시 입력 ]                │
└──────────────────────────────┘
```
