# 관리자 화면 참고 자료

## 전체 목적

전체 사용자와 기록 상태를 확인하는 관리자 전용 화면이다.

## 화면 구성

- 전체 사용자 수
- 전체 기록 수
- 사진 입력 수
- 텍스트 입력 수
- 저장 성공·실패 통계
- 최근 오류 로그
- 사용자 목록
- 날짜 필터

## 동작 규칙

- 일반 사용자는 이 화면을 볼 수 없다.
- 서버에서 권한을 먼저 확인한 뒤 데이터를 불러온다.
- 통계와 로그는 읽기 쉽게 구분해 보여준다.
- 민감한 정보는 최소한만 표시한다.

## 참고 배치

```text
┌──────────────────────────────┐
│ ← 뒤로        관리자        │
│                              │
│  전체 사용자 수              │
│  전체 기록 수                │
│  사진 입력 수                │
│  텍스트 입력 수              │
│                              │
│  최근 오류 로그              │
│  ┌────────────────────────┐  │
│  │ 로그 목록               │  │
│  └────────────────────────┘  │
│                              │
│  사용자 목록 / 통계 필터      │
└──────────────────────────────┘
```
