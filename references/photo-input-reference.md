# 사진 입력 화면 참고 자료

## 전체 목적

음식 사진을 업로드해 칼로리 추정의 기준을 만드는 화면이다.

## 화면 구성

- 사진 업로드 영역
- 카메라 촬영 버튼
- 갤러리 선택 버튼
- 사진 미리보기
- 삭제 또는 다시 선택 버튼
- 음식 이름 입력 또는 선택
- 양 입력
- 식사 종류 선택
- 메모 입력
- 칼로리 계산 버튼

## 동작 규칙

- 사진이 없으면 계산 버튼을 비활성화한다.
- 업로드 실패 시 다시 시도할 수 있게 한다.
- 불명확한 사진이면 보완 입력을 요청한다.
- 사진과 텍스트를 함께 반영할 수 있게 구성한다.

## 참고 배치

```text
┌──────────────────────────────┐
│ ← 뒤로        사진 입력      │
│                              │
│  [ 사진 업로드 영역 ]         │
│  ┌────────────────────────┐  │
│  │   사진 미리보기         │  │
│  └────────────────────────┘  │
│  [ 카메라 촬영 ] [ 갤러리 ]   │
│                              │
│  음식 이름: [ 자동/선택 ]     │
│  양:       [ 입력 ]          │
│  식사 종류: [ 아침/점심/저녁 ]│
│  메모:     [ 선택 입력 ]     │
│                              │
│  [ 칼로리 계산 ]              │
└──────────────────────────────┘
```
