# 텍스트 입력 화면 참고 자료

## 전체 목적

음식 이름, 양, 식사 종류를 직접 입력해 칼로리를 추정하는 화면이다.

## 화면 구성

- 음식 이름 입력창
- 양 입력창
- 식사 종류 선택
- 메모 입력창
- 칼로리 계산 버튼
- 입력 예시 문구

## 동작 규칙

- 음식 이름과 양은 필수 입력으로 둔다.
- 식사 종류는 정해진 값만 선택할 수 있게 한다.
- 빈 값이나 형식 오류가 있으면 바로 안내한다.
- 저장 전에는 사용자가 수정할 수 있게 한다.

## 참고 배치

```text
┌──────────────────────────────┐
│ ← 뒤로        텍스트 입력    │
│                              │
│  음식 이름: [             ]  │
│  양:       [             ]   │
│  식사 종류: [ 아침 ▼ ]       │
│  메모:     [             ]   │
│                              │
│  [ 칼로리 계산 ]              │
└──────────────────────────────┘
```
