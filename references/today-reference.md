# 오늘 기록 화면 참고 자료

## 전체 목적

오늘 먹은 음식 기록과 총 섭취 칼로리를 확인하는 화면이다.

## 화면 구성

- 오늘 날짜
- 오늘 총 섭취 칼로리
- 식사별 기록 목록
- 각 기록의 음식명
- 각 기록의 칼로리
- 기록 시간
- 상세 보기 또는 수정 버튼

## 동작 규칙

- 오늘 기록은 시간순으로 보여준다.
- 식사 종류별로 구분해서 보기 쉽도록 구성한다.
- 각 항목을 눌러 상세 화면으로 이동할 수 있게 한다.
- 메일 본문은 화면에 표시하지 않는다.
